# 📌 About The Project

**Faizan AI** is a full-stack, AI-powered personal portfolio website developed to showcase my academic background, technical skills, software development projects, Data Science and Machine Learning projects, internship experience, certifications, achievements and professional profile.

The project is designed to provide a modern and interactive way for recruiters, developers, collaborators and visitors to learn about my technical journey.

Unlike a traditional static portfolio, this project includes an **AI-powered conversational assistant called "Faizan AI 🤖"**.

The AI assistant allows visitors to ask natural-language questions about my professional profile and receive contextual responses.

The assistant can provide information about:

- Technical Skills
- Programming Languages
- Data Science
- Machine Learning

- Web Development

API keys are stored in environment variables.
.env files should not be uploaded to GitHub.
Sensitive credentials are not exposed in frontend code.
Production API credentials are stored in Render environment variables.
GitHub is used for source code and project documentation.

Never expose your real GROQ_API_KEY publicly.

⚙️ Local Installation
Step 1 — Clone Repository
git clone https://github.com/faizankhan07867/faizan-ai-portfolio.git

Move into the project:

cd faizan-ai-portfolio
🎨 Frontend Setup

Move into the frontend directory:

cd frontend

Install dependencies:

npm install

Start the development server:

npm run dev

The frontend will normally run at:

http://localhost:5173
🐍 Backend Setup

Open a second terminal.

Move into backend:

cd backend

Create a Python virtual environment:

python -m venv venv
Windows

Activate the virtual environment:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt
🔑 Environment Variables

Create a file:

backend/.env

Add:

GROQ_API_KEY=your_groq_api_key_here

Do not upload the .env file to GitHub.

▶️ Run Backend

From the backend directory:

uvicorn main:app --reload

The backend will normally run at:

http://127.0.0.1:8000

FastAPI documentation:

http://127.0.0.1:8000/docs
